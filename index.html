Academic Research

Smart Traffic Lights Using Local Edge AI

Smart Traffic Lights Using Local Edge AI: Architecture, Limitations, and Prioritization Protocols

H. Megha — Dept. of Computer Science (Data Science), BITM
Read Full Paper (PDF)

Abstract: Adaptive traffic control mitigates urban congestion by continuously adjusting signal timing based on real-time vehicle density. This research compares basic timed lights, cloud AI, and roadside local edge AI. By deploying lightweight computer vision models on Smart Pole units, decision latency drops to 0.5s while reducing continuous internet dependency and high bandwidth overheads.

System Architecture Decision Latency Data Bandwidth Usage Estimated Setup Cost
Basic Timed Signal 30.0 s Zero $200
Centralized Cloud AI 2.0 s High $2,500
Local Smart Pole Edge AI (Proposed) 0.5 s Low $1,200
Key Innovation: Dynamic signal override protocols for emergency priority corridors (ambulances) using acoustic and vision edge sensors.
